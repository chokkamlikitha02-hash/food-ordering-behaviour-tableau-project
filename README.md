# Food Ordering Behaviour & Consumer Trends Analysis

## Project Overview
This project provides a data-driven analysis of customer behavior, ordering preferences, and operational performance across major metro cities using Tableau. Analyzing 50,000 transaction records, the project uncovers insights into cuisine popularity, peak meal times, dining companion habits, customer satisfaction, and delivery efficiency.

---

## Key Features & Visualizations
* **KPI Demonstration:** High-level metrics showing Total Revenue (27.38M), Total Orders (50,000), Average Order Value (548), Average Rating (3 Stars), and Average Delivery Time (7 Mins).
* **Flavours Across Cities:** Heatmap analyzing cuisine demand distribution across key metro areas.
* **Cuisine Preference Analysis:** Breakdown of order volume across Desserts, Fast Food, Chinese, South Indian, North Indian, and Biryani.
* **Meal Type Dynamics:** Revenue contribution and order counts evaluated across Breakfast, Lunch, Dinner, and Snacks.
* **Dining Companion Insights:** Analysis of order volume segmented by dining setup (Alone, Family, Friends, Partner).
* **Delivery & Operational Benchmarks:** Geographic order distribution and rating consistency analysis.
